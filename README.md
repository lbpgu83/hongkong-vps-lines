## 线路才是香港VPS的命门：CN2、CMI、9929 分别指什么

先给结论：香港到大陆的物理距离决定了延迟下限很低，但能不能真跑出来，取决于回程走哪张网。

延迟参照（社区实测的大致区间）：香港到华南 10–30ms，到华东 30–50ms；对比之下东京 60–90ms，美西 130–180ms。这就是游戏加速、实时接口、面向国内访客的网站把香港排第一选项的原因。

常见回程线路速查：

- 普通国际线路：便宜款的默认选择，可能绕日本或美国，晚高峰丢包和限速都可能出现
- CMI：中国移动国际线路，移动用户直连体验好
- CN2 GT / CN2 GIA：中国电信精品网，GIA 双向优先、拥塞时有抢占权，属于香港线路的顶配
- AS9929：联通高端专线，联通用户的对口选择
- PCCW：老牌本地线路，品质参差，搬瓦工的香港 PCCW 机房已经下架，算是个信号

判断方法很朴素：看商家页面有没有写清三网回程；拿到机器先跑 traceroute 和 mtr 看路由，晚高峰 ping 一段时间看丢包。丢包率对体感的影响往往大过带宽数字——搬瓦工香港机型流量给得不大（入门款每月 500GB），仍有稳定用户群，原因之一就是其晚高峰实测下载能超过 700Mbps、三网丢包接近零。

## 常见问题

### 便宜香港VPS需要备案吗？

不需要。香港机房不受大陆备案要求约束，开通即可绑定域名建站，这也是香港 VPS 最经典的用法之一。内容合规仍需遵守当地法规。

### 电信、联通、移动用户分别怎么选线路？

电信优先 CN2（GIA 优于 GT），联通对口 AS9929，移动选 CMI 直连。不确定访客构成、或三网访客都有，直接看三网优化机型。

### 月付还是年付划算？

年付通常有折扣。以搬瓦工香港 CN2 GIA 为例，月付 $89.99、年付 $899.99，年付约等于八三折。但拿不准商家或线路时，建议先月付跑一个月路由和丢包，满意再转年付。
